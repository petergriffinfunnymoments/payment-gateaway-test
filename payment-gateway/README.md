# Платежный шлюз с поддержкой цифрового рубля

## Описание
Платежный шлюз для интеграции с внешними платежными системами (СБП, банковские карты, цифровые кошельки) с поддержкой цифрового рубля.

## Структура проекта
```
payment-gateway/
├── cmd/api/              # Точка входа приложения
├── internal/             # Внутренние модули
│   ├── transport/http/   # HTTP обработчики
│   ├── middleware/       # Промежуточное ПО
│   ├── validation/       # Валидация данных
│   ├── orchestrator/     # Оркестратор платежей
│   ├── antifraud/        # Антифрод система
│   ├── tokenization/     # Токенизация данных
│   ├── adapter/          # Адаптеры платежных систем
│   ├── notification/     # Уведомления
│   ├── logging/          # Логирование
│   └── database/         # Работа с БД
├── pkg/                  # Публичные пакеты
│   └── models/           # Модели данных
├── migrations/           # Миграции БД
├── configs/              # Конфигурационные файлы
└── frontend/             # Фронтенд интернет-магазина
```

## API Endpoints

### Создание платежа
```
POST /api/v1/payments
Headers:
  - Content-Type: application/json
  - X-API-Key: <ваш_api_ключ>
  - X-Idempotency-Key: <уникальный_ключ>

Body:
{
  "payment_info": {
    "amount": {
      "value": 1500.00,
      "currency": "RUB"
    },
    "payment_method": "SBP",
    "customer_data": {
      "phone": "+79991234567",
      "email": "customer@example.com"
    },
    "description": "Оплата заказа №123"
  }
}
```

### Получение статуса платежа
```
GET /api/v1/payments/status?id=<payment_id>
Headers:
  - X-API-Key: <ваш_api_ключ>
```

## Запуск

### Backend (API шлюз)
```bash
cd payment-gateway
go run cmd/api/main.go
# Сервер запустится на порту 8080
```

### Frontend (Интернет-магазин)
Откройте файл `frontend/payment.html` в браузере или используйте любой статический сервер:
```bash
python3 -m http.server 3000 --directory frontend
# Откройте http://localhost:3000/payment.html
```

## Методы оплаты
1. **СБП** - Система быстрых платежей (требуется номер телефона)
2. **Банковская карта** - Оплата картой (требуется номер карты, срок действия, CVV)
3. **Цифровой кошелек** - Оплата через цифровой кошелек (требуется ID кошелька)

## Страницы редиректа
- `frontend/success.html` - Страница успешной оплаты
- `frontend/error.html` - Страница ошибки оплаты

## Технологии
- **Язык**: Go
- **Фреймворк**: go-kit (планируется)
- **База данных**: PostgreSQL (планируется)
- **Масштабирование**: Docker контейнеры (планируется)
