## Описание компонентов по go-kit

### Transport Layer (cmd/api, internal/api)
- HTTP сервер для приема запросов от интернет-магазинов
- Middleware для аутентификации и первичной обработки
- Преобразование JSON в внутренние модели

### Service Layer (internal/validation, internal/orchestrator, etc.)
- Бизнес-логика каждой подсистемы
- Интерфейсы для взаимодействия между компонентами
- Использование паттерна Dependency Injection

### Repository Layer (internal/database)
- Работа с PostgreSQL
- CRUD операции для транзакций
- Миграции схемы БД

### Основные потоки данных:
1. API-шлюз → Валидация → Оркестратор
2. Оркестратор → Антифрод → Токенизация → Адаптер → ЭПС
3. ЭПС → Callback → Retry (при необходимости) → Notification → API-шлюз
4. Все события → Логирование → БД

## Используемые технологии:
- **Язык**: Go 1.21+
- **Фреймворк**: go-kit (микросервисная архитектура)
- **База данных**: PostgreSQL 15+
- **Миграции**: golang-migrate
- **Конфигурация**: Viper
- **Логирование**: Zap или Logrus
- **Тестирование**: testify, gomock
